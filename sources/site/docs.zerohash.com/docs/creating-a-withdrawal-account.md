# Source: https://docs.zerohash.com/docs/creating-a-withdrawal-account

In order to process a withdrawal via the portal, a Withdrawal Account is needed. A Withdrawal Account is a bank account or cryptocurrency address that has been approved by platform admins.

## 

Adding a new Withdrawal Account

1. Log into the portal and and find the **Participant** header, **Withdrawals** sub-header

![](https://files.readme.io/41fc739f34388c549d4a46257a87b74ee916a26685fc0024fea37cb2b6706c27-blurred_withdrawal_dash_screen.png) 

2. Select the asset you want to create a withdrawal account for and select **Create New Account**

![](https://files.readme.io/6600806ef0982ce64d4e54bcbfec98d4fac2b23b9d1b64670bdc7cdc43d3ada2-btc_create_new_account.png) 

3. For Crypto accounts, fill out the fields required. Ensure that the wallet address is correct.

![](https://files.readme.io/6e23aed2f62d194c72344f0ed600d49575e9a501af579bc2cd2b781c1afad323-Screenshot_2025-12-08_at_2.53.35PM.png) 

4. For Fiat accounts, select the type that is most appropriate for your transfer. If a memo is needed, please include it in the Recipient Instructions field.

![](https://files.readme.io/06656a2cc4f8d03b91975577a16d10dcd326aaaed363862de85e6ba9bb72e9be-Screenshot_2025-12-08_at_2.54.59PM.png) 

5. Once the Withdrawal Account is created, two admins need to approve the account. Once approved, it can then be used to create withdrawals.
