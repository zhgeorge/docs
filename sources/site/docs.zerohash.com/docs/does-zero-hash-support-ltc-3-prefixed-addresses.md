# Source: https://docs.zerohash.com/docs/does-zero-hash-support-ltc-3-prefixed-addresses

zerohash is able to support sending LTC to both L-prefixed and M-prefixed addresses.

The 3-prefixed address is just the legacy format of the M-prefixed addresses (they're the same address only formatted differently). Addresses submitted with the legacy M-prefixed addresses will automatically be converted.
