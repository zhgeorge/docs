# Source: https://docs.zerohash.com/docs/whitelist-ip-addresses

Being a regulated Money Service business in the US and globally in other jurisdictions, we have high security standards. In order to hit our API's, you must contact a zerohash representative and pass them the Corporate VPN IP addresses you'd like hit the API from. These addresses are added to the **Global IP Whitelist**. If an IP is not added to this list, no API keys associated with your Platform will be able to hit the API.

From there, you can get more granular and provision various keys to be hit from certain IP addresses. This can be done when you first create the API key or after the fact via the API Key page under the Administration section:
