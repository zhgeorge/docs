# Source: https://docs.zerohash.com/docs/which-bitcoin-cash-bch-chain-do-you-support

zerohash currently only supports the BCH ABC chain which is referred to as "Bitcoin Cash" with the product symbol "BCH".

In addition, we support the CashAddr address format when submitting BCH withdrawals that begin with "bitcoincash:address". If withdrawals are submitted with the Legacy address format, they will automatically be converted.
