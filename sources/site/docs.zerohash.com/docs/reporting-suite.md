# Source: https://docs.zerohash.com/docs/reporting-suite

zerohash provides a full self-service reporting suite via the zerohash [portal](https://portal.zerohash.com/). Although all data is also accessible via the API, the portal reporting tool allows non-developers to quickly and independently summon .csv files.

# 

Available Reports

| Report | Description |
| --- | --- |
| Account Balances | View historical balances **after movements have occurred** |
| Deposits | View all deposits into your zerohash account |
| Network Fees | View all network fees for **non ERC-20 coins** |
| Trades | View all trading activity on your Platform |
| Withdrawals | View all withdrawals into your zerohash account |

# 

How to generate reports

1. Navigate to the Reports section of the portal.

 ![](https://files.readme.io/9e8af1c-image.png)

2. Select a Report to run.

 ![](https://files.readme.io/dcb61c2-image.png)

3. Choose Participant or Platform

 1. **Participant**: All data downloaded will pertain to your participant

 2. **Platform**: All data downloaded will pertain to your participant + any customers

 ![](https://files.readme.io/50350b7-image.png)

4. Choose a Start and End Date.

 1. Start date and end date can be the same.

 2. Some reports will only have one date option available.

 ![](https://files.readme.io/cbea1b8-image.png)

5. Click 'Generate Report'.

 ![](https://files.readme.io/423e450-image.png)

6. Click Download and the report will appear in the bottom left of the browser.

 ![](https://files.readme.io/9a40574-image.png)
