# Source: https://docs.zerohash.com/docs/restricted-activities-for-new-york-participants

All platforms can access New York persons. However, there is functionality that is not available to New York persons at this time.

| Endpoint | Operation | Allowed in NY? |
| --- | --- | --- |
| `POST /deposits/UMA` | deposits.createUMA<br>deposits.lnurlp<br>deposits.payreq<br>deposits.updateUMA | No |
| `POST /participants/customers/minor` | participants.createCustomer | No |
| `POST /withdrawals/UMA` | withdrawals.UMA | No |
