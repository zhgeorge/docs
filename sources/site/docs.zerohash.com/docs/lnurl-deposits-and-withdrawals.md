# Source: https://docs.zerohash.com/docs/lnurl-deposits-and-withdrawals

Currently LNURL deposits and withdrawals are on the roadmap but do not have an estimated launch date. Please reach out to your zerohash team if there are specific features you would like to prioritize.

### 

Upcoming features

Below are a list of features related to non-UMA Lightning Transactions that are on the roadmap for a future release:

- LNURL Lightning Network withdrawals via /withdraw/
 - Support for sending BTC via the LNURL specification
- LNURL Lightning Network withdrawals via /convert\_withdraw/
 - Convert fiat to BTC then send over the Lightning Network in one call
- LNURL Lightning Network deposits
 - Generate an LNURL invoice to receive assets
