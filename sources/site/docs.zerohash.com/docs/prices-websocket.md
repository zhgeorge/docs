# Source: https://docs.zerohash.com/docs/prices-websocket

zerohash offers a way for clients to subscribe to a live price-feed for **_quotes_** .

## 

Supported Symbols

The supported instruments varies by environment you are subscribing to. To get a list of supported instruments on the websocket API, you can make a call to the list symbols topic documented [here.](https://docs.zerohash.com/reference/listing-available-symbols)

## 

Price Update

To start a quote price subscription, you can use the supported symbols with the message-type as `price-update`. For more information on the quote websocket API, check our documentation [here](https://docs.zerohash.com/reference/price-updates).
