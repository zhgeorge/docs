# Source: https://docs.zerohash.com/docs/on-off-ramps

## 

Use Cases

- **Crypto Wallet-owned Onramp:** Own the onramp experience yourself without needing to integrate multiple 3rd party onramp solutions
- **3rd-Party Onramp:** Build a plug-and-play onramp that can be embedded within crypto wallets

## 

Key Features

- **Simple technical integration:** Only 3 executable endpoints are required to build an on and off ramp
- **Broad asset coverage:** Allow your users to on ramp into and off ramp out of 60+ crypto assets (see supported trading instruments [here](https://docs.zerohash.com/page/production-environment)).
- **Ultimate Flexibility:** Configure the length of each quote - we support 5 seconds, 30 seconds, 1 minute, 5 minutes, and 15 minutes.
