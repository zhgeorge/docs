# Source: https://docs.zerohash.com/docs/sdk-index

The zerohash SDKs let you embed regulated stablecoins/crypto, payments, and onboarding flows directly into your product. Each SDK is a drop-in component that handles the regulated surface such as KYC, custody disclosures, signing, and compliance copy so your team can focus on the product wrapper around it.

**ℹ️ Note: All visuals and screenshots from the SDK documentation are conceptual only. Our SDKs are constantly updated and visuals may not reflect the current experience.**

# 

Available SDKs

- [Onboarding SDK](https://docs.zerohash.com/docs/onboarding-experience-sample) - KYC and identity verification widget
- [Auth SDK](https://docs.zerohash.com/docs/auth-standalone) - link wallets with popular exchanges
- [Account Funding Deposits SDK](https://docs.zerohash.com/docs/fund-integration-guide-onboarding-api-fund-sdk-sdk) - enable stablecoins/crypto payouts to your platform account
- [Account Funding Withdrawals SDK](https://docs.zerohash.com/docs/wallet-link-sdk-integration-guide) - enable withdrawals in stablecoins/crypto from your platform account
- [Payins SDK](https://docs.zerohash.com/docs/payins-integration-guide) - accept payments via the Auth payins flow
- [Payouts SDK](https://docs.zerohash.com/docs/payouts-sdk-integration-guide) - disburse funds via the Auth payouts flow
- [Mobile SDKs](https://docs.zerohash.com/docs/mobile-sdks) - Native iOS / Android wrappers

# 

Choosing an SDK

Partners can start with the **Onboarding SDK** to satisfy KYC requirements, then layer on Buy/Sell, Payins, or Payouts depending on the use case. The SDKs share a common authentication scheme and theming layer (see Appearance & Branding) so adding a second SDK once the first is integrated is a small lift.

If your flow lives entirely server-side or you need finer control than the embedded widgets allow, use the REST API directly - see the [API Reference](https://docs.zerohash.com/reference/overview) and [Recipes](https://docs.zerohash.com/recipes).

# 

Prerequisites

- A zerohash Cert or Prod platform - see [Getting Started](https://docs.zerohash.com/docs/getting-started)
