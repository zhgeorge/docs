# Source: https://docs.zerohash.com/docs/application-review-process

Once an application is submitted, each authorized signer listed on the application will be notified. An authorized signer must review the application for accuracy and attest that all information is up to date and accurate before zerohash will accept the application as complete.

Once fully submitted and signed, zerohash AML/KYC staff will review the information and the attached supporting documentation. Where needed, zerohash staff will contact the applicant for any missing or incomplete information. When the application has been fully reviewed, the application is sent for a final review and formal approval or rejection by the zerohash Participant Committee.
