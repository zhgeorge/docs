## 

Bankers Rounding

Taking `DOGE/USD` as an example:

- Quantity Precision: 0.1 DOGE/USD
- Price: $0.1651 per DOGE/USD (as of June 30, 2025)

### 

Placing a $100 Order

If you place an order with a **notional value of $100**, the number of DOGE you would receive is calculated as:

- `$100 ÷ $0.1651 ≈ 605.6935191 DOGE`

Since DOGE has a **quantity precision of 0.1**, this amount is rounded down to the nearest tenth:

- `605.6935191 → 605.6 DOGE`

Placing an order for a notional of $100 DOGE, you would receive ($100 / $0.1651 per DOGE) 605.6935191 DOGE. The quantity precision for DOGE is to one decimal place, so this figure will always round **down** to the nearest first decimal (in this case 605.6 DOGE).

The trade notional for this trade will then be (605.6 DOGE \* $0.1651 per DOGE) = $99.98456. Due to bankers rounding at the cent level, the cost of this trade will be $99.98.

### 

Final Trade Notional

The final trade notional is then:

- `605.6 DOGE × $0.1651 = $99.98456`

After applying bankers rounding to the nearest cent, the final cost of the trade is:

- `$99.98456 → $99.98`
