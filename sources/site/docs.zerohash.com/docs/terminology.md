# Source: https://docs.zerohash.com/docs/terminology

**Participant:** Most broad term to describe a zerohash network participant. This can be Customer, Platform, Liquidity Provider, etc.

**Platform:** A type of participant that operates a customer-facing platform.

**Customer:** A type of participant that is a customer of a platform. This may be a human (natural person) or a business (non-natural person).

**User:** An employee of a Platform that has access to our Client Portal.

**Client Portal:** User interface that Platform employees can use to view balances and activity, generate API keys, and download reports. See guide [here](https://zerohash-group.readme.io/docs/onboarding).
