# 

Rewards

Using the light-weight and singular API endpoint [POST /rewards](https://docs.zerohash.com/reference-link/post_rewards), zerohash-connected platforms can offer crypto rewards products.

## 

Use Cases

- **Reward Programs:** Offer an alternative reward system for your credit/debit program.

## 

Key Features

- **Simple:** Reward transactions are made through a single endpoint.
- **Full asset support:** Any instrument listed [here](https://zerohash-group.readme.io/docs/supported-assets-instruments) is supported.
- **Instant settlement:** Crypto rewards are settled instantly to the Customer.

## 

API Reference

- [POST /rewards](https://docs.zerohash.com/reference-link/post_rewards)

# 

Awards

Our Awards product allows Platforms to distribute crypto awards to your Customers.

## 

Use Cases

- **Marketing promotions:** Whether you're launching your first crypto product or have been offering it for years, engage customers by awarding them crypto

## 

Key Features

- **Simple 2-step process:** Platforms first fund their own account with crypto, then distribute the awards to Customers.
- **Full asset support:** Any instrument listed [here](https://zerohash-group.readme.io/docs/supported-assets-instruments) is supported.
- **Instant settlement:** Crypto rewards are settled instantly to the Customer.

## 

API Reference

- [POST /awards/fund](https://docs.zerohash.com/reference-link/post_awards-fund)
- [POST /awards/distribute](https://docs.zerohash.com/reference-link/post_awards-distribute)
