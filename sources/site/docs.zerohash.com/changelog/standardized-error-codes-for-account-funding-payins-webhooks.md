Release Details

**Release Date:** May 29, 2026

# 

Summary

This release publishes the full, official set of `status_reason_code` values returned on webhooks across the **Account Funding** and **Payins** products. Each product maintains its own discrete set of codes, fully documented below, so platforms can build deterministic error handling logic against a stable, predictable set of values. 

No changes have been made to webhook structure, delivery behavior, or existing successful (true) status codes.

See Account Funding error codes [here](https://docs.zerohash.com/reference/fund-transaction-update) and Payins error codes [here.](https://docs.zerohash.com/reference/payins-transaction-updates#status-reason-codes)
