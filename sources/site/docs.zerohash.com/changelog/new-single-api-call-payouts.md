## 

Release Details

**Release Date:** June 24th, 2026

## 

Release Type

Informational, no action required from platforms

## 

Summary

We've introduced [**Single API Call Payouts**](https://docs.zerohash.com/docs/streamlined-payouts), designed for licensed financial institutions and organizations managing nested payors. It works best when you're not building custom payout UI yourself, and your workflows don't need to track state internally.

We've also renamed the first generation of our Payouts product to [**Modular Payouts**](https://docs.zerohash.com/docs/modular-payouts) - built for platforms that want to own the payout experience end-to-end, manage complex creator or seller networks, and maintain full control over state, UX, and compliance tracking.
