## How Zero Hash Works

Zero Hash sits between your platform and the regulated digital asset ecosystem. You integrate once via API or SDK; Zero Hash handles custody, compliance, liquidity, and settlement on the back end.

<Steps>
  <Step title="Get Platform Access">
    Contact the Zero Hash team to provision your Cert (sandbox) and Prod environments. You'll receive API credentials for both. See [Get Platform Access](/docs/get-platform-access).
  </Step>
  <Step title="Generate API Keys">
    Log in to the [Client Portal](https://portal.zerohash.com) to create and manage API keys. Keys are scoped to your platform and used to sign every request. See [Generate API Keys](/docs/generate-api-keys).
  </Step>
  <Step title="Onboard Customers">
    Create participant records for your end users via the Onboarding API or the drop-in Onboarding SDK. Zero Hash handles KYC and compliance disclosures. See [Onboard a Customer](/docs/onboard-a-customer).
  </Step>
  <Step title="Build Your Use Case">
    Choose your integration path — crypto trading via [RFQ](/docs/request-for-quote) or [CLOB](/docs/central-limit-order-book-3), [stablecoin payouts](/docs/payouts), [fiat ACH deposits](/docs/fiat), [staking](/docs/staking), or [settlement](/docs/settlements-as-a-service).
  </Step>
</Steps>
