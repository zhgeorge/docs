## Overview

Single API Call Payouts reduces the payout process to just 2 steps:

1. Onboard Payor (one-time setup)
2. Initiate Payout (per transaction) - Single API call with complete payout details, including the ultimate payor and beneficiary onboarding.

After your Payor is registered, each payout requires only a single API call. zerohash orchestrates all intermediary steps internally: participant verification, compliance checks, account linking. Your platform can focus on business logic rather than workflow management.
