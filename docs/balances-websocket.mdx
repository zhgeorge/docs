Zero Hash offers two real-time WebSocket feeds that let your platform react instantly to events without polling REST endpoints: the **Balances WebSocket**, which pushes a message every time any account balance under your platform changes, and the **Prices WebSocket**, which delivers live bid/ask quotes for all supported trading pairs. Together, these feeds power customer-facing dashboards, internal operations monitors, deposit confirmation flows, and price display components without the latency and overhead of repeated REST calls.

## Balances WebSocket

The Balances WebSocket is a private feed that covers all accounts belonging to your platform participant and all customer accounts whose `account_group` matches your platform code.

### Connection and Authentication

Connect to the private WebSocket endpoint and authenticate using your API credentials before subscribing. Refer to the [Private Socket Feed reference](https://docs.zerohash.com/reference/private-websocket-api) for the full connection specification, including the authentication handshake.

### Subscription

Once connected, send the subscription message to begin receiving balance data. The server responds with an `initial-balance` snapshot, then streams `balance-updated` events as changes occur.

### Maintaining the Connection

Send a **ping** message every 20 seconds to keep the connection alive. If no ping is received within the interval, the server closes the connection.

```json
{
  "messageType": "ping"
}
```

### Balance Update Event Fields

<ResponseField name="account_id" type="string">
  The unique identifier for the account whose balance changed.
</ResponseField>

<ResponseField name="participant_code" type="string">
  The participant who owns this account. For customer accounts, this is the customer's code; for platform accounts, this is your platform code.
</ResponseField>

<ResponseField name="account_group" type="string">
  The platform group this account belongs to. For customer accounts, this matches your platform code, allowing you to identify which customers belong to your platform.
</ResponseField>

<ResponseField name="account_type" type="string">
  The balance type: `available`, `collateral`, or `staked`. For standard trading accounts, this is `available`.
</ResponseField>

<ResponseField name="balance" type="string">
  The updated account balance after all movements in this run have been applied.
</ResponseField>

<ResponseField name="run_id" type="integer">
  A numeric identifier grouping one or more movements that occurred atomically. Runs are collections of potentially multiple movements.
</ResponseField>

<ResponseField name="run_type" type="string">
  The category of activity that triggered this balance change: `deposit`, `withdrawal`, `trade`, etc.
</ResponseField>

<ResponseField name="movements" type="array">
  The individual balance change entries within this run. Each movement is the most granular unit of a balance change and includes `movement_type` and `change` (signed decimal).
</ResponseField>

### Movement Types

The `movement_type` field in each movement entry tells you what kind of event caused the change:

| `movement_type` | Description |
|---|---|
| `deposit` | On-chain deposit confirmed |
| `withdrawal_pending` | Withdrawal submitted, pending on-chain confirmation |
| `withdrawal_confirmed` | Withdrawal confirmed on-chain |
| `withdrawal` | Net withdrawal debit applied to available balance |
| `trade` | Balance change due to trade settlement |
| `staking` | Balance movement related to a staking event |

### JavaScript Connection Example

The following example connects to the Zero Hash Balances WebSocket, handles the initial snapshot, listens for live updates, and sends a ping every 20 seconds to maintain the connection.

```javascript
const WebSocket = require('ws');

const WS_URL = 'wss://api.zerohash.com/ws/balances'; // confirm URL with your solutions engineer
const API_KEY = process.env.ZH_API_KEY;
const API_SECRET = process.env.ZH_API_SECRET;

const ws = new WebSocket(WS_URL);

ws.on('open', () => {
  console.log('Connected to Zero Hash Balances WebSocket');

  // Authenticate and subscribe
  ws.send(JSON.stringify({
    messageType: 'subscribe',
    apiKey: API_KEY,
    // Include HMAC signature per Zero Hash auth spec
  }));

  // Send ping every 20 seconds to keep connection alive
  setInterval(() => {
    if (ws.readyState === WebSocket.OPEN) {
      ws.send(JSON.stringify({ messageType: 'ping' }));
    }
  }, 20000);
});

ws.on('message', (data) => {
  const message = JSON.parse(data);

  if (message.messageType === 'initial-balance') {
    console.log('Received initial balances:', message.body.length, 'accounts');
    // Populate your balance store with the snapshot
    message.body.forEach(account => {
      updateBalanceStore(account);
    });
  }

  if (message.messageType === 'balance-updated') {
    const update = message.body;
    console.log(`Balance update: ${update.participant_code} ${update.asset} → ${update.balance}`);

    // Update your UI or internal state
    updateBalanceStore(update);

    // Trigger downstream actions based on run_type
    if (update.run_type === 'deposit') {
      notifyUserOfDeposit(update);
    }
  }
});

ws.on('close', () => {
  console.log('WebSocket connection closed — reconnecting...');
  // Implement reconnect logic with exponential backoff
});

ws.on('error', (err) => {
  console.error('WebSocket error:', err.message);
});

}
```

## Prices WebSocket

The Prices WebSocket delivers a real-time stream of quote prices for all supported trading symbols. Use this feed to power live price displays, quote widgets, or automated trading triggers in your platform.

### Supported Symbols

The set of available instruments varies by environment (sandbox vs. production). To discover which symbols are supported in your environment, query the list symbols topic:

```
List symbols topic: see the Zero Hash WebSocket API reference → Listing Available Symbols
```

### Subscribing to Price Updates

To start a quote price subscription, send a subscription message with the `message_type` set to `price-update` and include the symbols you want to subscribe to.

```json
{
  "messageType": "price-update",
  "symbols": ["BTC/USD", "ETH/USD", "SOL/USD"]
}
```

Each incoming message includes the current bid, ask, and mid-price for the subscribed symbol. Refer to the [Prices WebSocket API reference](https://docs.zerohash.com/reference/price-updates) for the full message format and field definitions.

<Tip>
  Use the Prices WebSocket for displaying indicative quotes in your UI. For executable quotes used to confirm trade amounts before order submission, always call the trade quote endpoint to get a firm, time-bound price.
</Tip>
